Hour-by-hour quantile forecast of Twitch's concurrent viewers in the Grand Theft Auto VI category on release day, 2026-11-19 (UTC). The program learns the release-day shape from the case's comparable launches — each one's hourly counts divided by its own hour-1 mean, in log space — and forecasts each hour as hour 1's print times the typical ratio, with a spread widened by the random-walk term. Built by an AI agent for make.fun's "Forecast GTA VI's launch-day Twitch viewers hour by hour" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
